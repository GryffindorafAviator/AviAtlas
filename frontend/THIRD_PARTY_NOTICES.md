# Third-party design attribution

The bright Cassette Futurism component stylesheet in `src/cassette.css` is adapted directly from [NovusGFX / Retro Design System — 15 Cassette Futurism](https://github.com/NovusGFX/retro-design-system/blob/main/styles/15-cassette-futurism/index.html): inset panels, physical button treatments, indicator lights, and instrument labels. The original terminal, status-bar, panel-inset, button, and input rules are retained with a light palette and reduced shadows. `src/style.css` contains application layout and responsive overrides.
